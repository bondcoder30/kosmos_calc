Блок доставки — превью

Один общий iframe-виджет на все торты. Связывается с калькулятором торта автоматически — калькулятор шлёт текущую сумму по BroadcastChannel, доставка ловит и пересчитывает. Никакого JS на стороне сайта писать не нужно: просто вставьте два iframe на одну страницу.

  • Связка автоматическая: оба iframe на одном домене (github pages) — общаются через BroadcastChannel('kosmos-cake'). При любом изменении веса/ярусов/начинки в калькуляторе блок доставки моментально пересчитывает итог.
  • Альтернатива (если нужно явно передать значения): URL-параметры ?total=…&cake=…&weight=…&tiers=…&filling=…&tiered=0|1 либо postMessage из родителя.
  • Фиолетовый кружок «самовывоз» автоматически блокируется для ярусных тортов.
  • «Продолжить заказ с администратором» копирует текст заказа в буфер и открывает @kosmoscake.
  • Хотите всё одним iframe? Используйте cakes-mobile-full — мобильная объединённая версия.
