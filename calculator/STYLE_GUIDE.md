# Инструкция по правкам стиля

Все правки **визуала** делаются в одном файле:

```
calculator/style.css
```

После любой правки — закоммитить и запушить (GitHub Desktop → Commit → Push), и через 1–2 минуты всё обновится на сайте и во всех iframe-ах сразу. Ничего пересобирать руками не надо — все 30 калькуляторов тортов используют этот же `style.css`.

---

## 1. Цвета (палитра)

Файл `style.css`, строки **32–40** — блок `:root{ ... }`.

```css
:root{
  --bg:        #cfcfcf;   /* фон калькулятора (серый) */
  --red:       #D2363C;   /* большие цифры, заголовок-описание и кнопка отправки */
  --pink:      #F16471;   /* розовый: название торта, +/-, мелкий текст, линии, лейблы */
  --rose:      #F16471;   /* розовый при наведении (hover) */
  --red-deep:  #D2363C;   /* красный при наведении на кнопку «Отправить» */
  ...
}
```

| Что хочешь поменять | Какую переменную править |
|---|---|
| Серый фон калькулятора | `--bg` |
| Большие красные цифры (стоимость, вес, ярусы) | `--red` |
| Название торта (розовое крупное) | `--pink` |
| Кнопки +/− | `--pink` (и `--rose` для hover) |
| Бордеры выпадашек и кружочки фикс-веса | `--pink` (hover — `--rose`, выбран — `--red`) |
| Кнопка «Отправить заказ» (фон) | `--red` (hover — `--red-deep`) |

Достаточно вписать новый hex-код один раз — он применится во всех нужных местах.

## 2. Шрифты

Файл `style.css`, строки **7–24**.

В калькуляторе используется два шрифта:

- **ALS Beast Ultra** (`var(--display)`) — для крупных надписей: название торта, белое описание, цифры, лейбл «Сколько килограмм?», «Итоговая стоимость».
- **Golos Text Regular** (`var(--text)`) — для всего мелкого: подпись «Подходит для…», начинки, дропдауны, кнопка «Отправить заказ».

Если захочешь подменить шрифт целиком — поменяй название в одной строке:

```css
:root{
  ...
  --display: 'ALS Beast', system-ui, sans-serif;   /* строка 38 */
  --text:    'Golos Text', system-ui, ...;          /* строка 39 */
}
```

Файлы шрифтов лежат в `calculator/assets/`. Если меняешь на другой — добавь .otf/.ttf туда же и поменяй пути в `@font-face` (строки 7–24).

### Мобильная версия

В самом конце `style.css` — блок `@media (max-width:420px)` (строки 196–207).

## 5. Чего НЕ нужно править руками

- `core.js` — там логика (цены начинок, формулы расчёта). Если меняется цена начинки — это там, объект `FILLING_PRICES` (строки 5–12).
- `cakes/*/*.html` — это 30 готовых файлов калькуляторов. Все они подтягивают один и тот же `style.css`. Никогда не правь их по отдельности.
- `assets/` — шрифты и иконки.

---

## 6. Быстрый чек-лист «как поменять и увидеть результат»

1. Открыла `calculator/style.css` в любом редакторе (хоть в Блокноте).
2. Нашла нужную строку из таблицы выше, поменяла число/цвет.
3. Сохранила.
4. GitHub Desktop → видно изменение → Commit (с любым описанием) → Push origin.
5. Подождала ~1 минуту → обновила страницу с калькулятором — изменения применились.

То же самое касается `core.js`, если меняется цена начинки.

## 7. Если хочется поменять формулу или поведение

Это уже в `core.js`:

| Что | Где |
|---|---|
| Цены начинок (рубли за кг) | `FILLING_PRICES` — строки 5–12 |
| Наборы начинок по типам тортов | `FILLING_SETS` — строки 16–23 |
| Логика типа 1 (ярусный торт) | `renderTieredCake` — строки 62–139 |
| Логика типа 2 (фикс. вес 2.5/3.5) | `renderFixedCake` — строки 145–193 |
| Логика типа 3 (плоский по весу) | `renderWeightCake` — строки 199–260 |

Параметры конкретного торта (минимальный вес, минимальное число ярусов, стоимость декора, набор начинок) лежат в его HTML-файле в папке `calculator/cakes/...`. Если нужно подкрутить параметр одного торта — это там, наверху файла, в объекте `cake = { ... }`.
