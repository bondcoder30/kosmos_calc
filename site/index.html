Kosmos cake — превью страниц сайта

Каждая страница — готовый HTML для iframe (Tilda / Readymag и т.д.). Ниже — главные, страница «о нас» и все страницы тортов (десктоп и мобилка), с кнопкой копирования сниппета. Фото торта: положите файлы в site/photos raw/<id>/ и выполните python site/import_photos_raw.py, затем python site/build_site_pages.py.
